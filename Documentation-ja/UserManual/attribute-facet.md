# 基本属性(Attribute)ファセット

IFCモデルの各エンティティには、標準化された **基本属性** のリストがあります。**基本属性** は、すべてのIFCエンティティに関連付けられた基本データの限定されたセット（通常10未満）です。これらはIFC標準によって固定されており、カスタマイズすることはできません。

以下は、一般的な基本属性とその意味です：

- **GlobalId**: コンピュータ専門家にとって有用な要素の一意のID
- **Name**: 人間がオブジェクトを識別するための短い名前、コード、番号、またはラベル。図面やスケジュールでオブジェクトに注釈を付ける場合、Nameが表示されるべきものです。例えば、ポンプのNameは「P-10-A」かもしれません。
- **Description**: 通常、名前の長い形式で、人間にとって記述的で読みやすいように書かれています。例えば、ポンプの説明は「給水ポンプ」かもしれません。
- **Tag**: これは他のBIMアプリケーションにリンクする可能性のあるIDです。例えば、IFCモデルがRevitやArchiCADを使用して作成された場合、RevitやArchiCADの要素IDを保持する可能性があります。

IFCエンティティの定義にとって重要ではない情報は、**基本属性** ではなく **プロパティ** として格納されます。詳細については、[**プロパティファセット**](https://claude.ai/chat/property-facet.md)の文書を参照してください。

この理由から、**基本属性** は特定の要素に対する **適用対象** を指定する、または特定の要素が特定の方法で識別、命名、または記述されるべきという **要求条件** を指定するための良い方法です。

IFCクラスでどの **基本属性** が利用可能で、その潜在的な値が何であるかを確認するには、IFC文書をチェックする必要があります。以下は、IFC4X3_ADD2スキーマで有効な **基本属性** のリストを見つける方法です。すべてのIFCバージョンで手順は同様です。

1. 指定しているIFCクラスの文書ページを参照します。例えば、[これはIfcWallの文書ページです](http://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcWall.htm)。
2. 文書の **基本属性** セクションまでスクロールダウンします。デフォルトでは、すべての基本属性が表示されているわけではないことに注意してください。「_Click to show hidden inherited attributes_」を押してすべての基本属性を表示します。IFC4の場合、「_Attribute inheritance_」テキストヘッダーをクリックして、すべての基本属性のテーブルを切り替えます。
3. **基本属性** テーブルには、各 **基本属性** の **名前** が表示されます。番号が付いておらず、斜体になっている **基本属性** は指定することが許可されていないことに注意してください。列挙型(Enumeration)の **基本属性** のみが指定可能です。例えば、IfcWallの **Name** 基本属性は指定できますが、**ConnectedTo** は指定できません。

文書をチェックする代わりに、IDS作成ソフトウェアが有効な **基本属性** を絞り込むのに役立つ場合があります。

命名規則に従い、要素を正確に記述することは、AECO業界の多くの用途にとって重要です。この理由から、**要件** の **適用対象** と **要求条件** の両方のセクションで **基本属性ファセット** を使用することは非常に一般的です。

## パラメータ

|パラメータ|必須|制限許可|許可値|意味|
|---|---|---|---|---|
|**Name**|✔️|✔️|IFCスキーマからの有効な基本属性名|基本属性は存在し、空でない値を持つ必要があります。|
|**Value**|❌|✔️|基本属性のデータ型に適した任意の値|基本属性の値は一致する必要があります。詳細については[DataType文書](https://claude.ai/ImplementersDocumentation/DataTypes.md#xml-base-types)を参照してください。|

## 例

|適用対象の意図|要求条件の意図|ファセット定義|
|---|---|---|
|「ABC123」という名前を持つ任意のエンティティ|エンティティ（例：Project）は「ABC123」という名前でなければならない|Name="Name", Value="ABC123"|
|任意のエンティティ（通常はIfcMapConversion）でEastingが312345のもの|エンティティ（例：IfcMapConversion）は原点がEasting 312345にあるように地理的に配置されなければならない|Name="Easting", Value="312345"|
|「WT」で始まり、その後に2桁の数字が続く名前を持つ任意のエンティティ（WT01、WT02など）|要素はWT01、WT02などの命名スキームを持つ必要がある|Name="Name", value="WT[0-9]{2}"|
|空でない説明を持つ任意のエンティティ|エンティティは説明を持つ必要がある|Name="Description"|
|任意のエンティティ（通常はIfcTask）で、Statusが「NOTSTARTED」、「STARTED」、または「COMPLETED」のいずれかに設定されているもの|エンティティのStatus（例：IfcTask）は「NOTSTARTED」、「STARTED」、または「COMPLETED」のいずれかで記入される必要がある|Name="Status", Value=["NOTSTARTED", "STARTED", "COMPLETED"]|
|任意のエンティティ（通常はIfcTaskTime）で、DurationTypeがWORKTIME（カレンダーベース）に設定されているもの|期間タイプ（例：IfcTaskTime）は経過時間ではなく、カレンダーベースでなければならない|Name="DurationType", Value="WORKTIME"|
