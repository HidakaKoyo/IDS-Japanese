# 材料(Material)ファセット

IFC内の要素（例：壁、扉、窓等）および要素タイプ（例：壁タイプ、扉タイプ、窓タイプ等）には、**Material** が関連付けられている場合があります。これらの **Materials** は、化学的な **Materials** とは対照的に、一般的に建設資材として指定されます。例えば、2つの異なる等級のコンクリートは、2つの別々の **Materials** として扱われます。

最も単純なケースでは、要素は単一の **Material** を持つ場合があります。例えば、椅子は「木材」材料から作られている場合があります。**Material ファセット** により、この **Material** を持つ要素でフィルタリングできます。

要素は、3つの可能なシナリオで複数の **Materials** を持つ場合もあります：

- **レイヤー材料** ：要素（例：壁またはスラブ）は、厚さを持つ材料レイヤー（例：スタッドレイヤー、断熱レイヤー、石膏レイヤー）の観点からパラメトリックに定義されます。各レイヤーは異なる **Material** を持つ場合があります。
- **プロファイル材料** ：要素（例：柱または梁）は、パスに沿って押し出されたプロファイル（例：C形プロファイル、Z形プロファイル、またはI形プロファイル）の観点からパラメトリックに定義されます。複合柱と梁は、異なる **Materials** からの複数のプロファイルを持つ場合があります。
- **構成材料** ：要素（例：窓またはスラブ）において、要素の一部が異なる **Materials** で作られている（例：窓ガラスと窓枠）か、混合されている（例：コンクリートスラブは、セメント、骨材等の割合で構成されている場合があります）

![Material ファセット](Graphics/material-facet.png)

**Material ファセット** により、それらの **Materials** の1つが指定された **Material** と一致する要素をフィルタリングできます。

コスト計算、スケジューリング、持続可能性分析、建設業務パッケージなど、多くの分野が正確な **Material** 関連付けに依存しています。**Material ファセット** は、ドメイン固有の情報要件(Specification)に特に有用です。

## パラメータ

| パラメータ | 必須 | 制約許可 | 許可値                                                                                                                                                                                                                                                                                         | 意味                                                                                                                                                                                                                                                        |
| --------- | ---- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Value** | ❌   | ✔️       | 任意の材料名または材料カテゴリ。材料名は通常、プロジェクトまたは地域の慣習に固有です。材料カテゴリは、'concrete'、'steel'、'aluminium'、'block'、'brick'、'stone'、'wood'、'glass'、'gypsum'、'plastic'、または'earth'のいずれかであることが推奨されます。 | 要素は、指定された名前またはカテゴリを持つ **Material** で作られている必要があります。複数の **Materials** がある場合、その名前またはカテゴリを持つ任意の **Material** 、**Layer** 、**Profile** または **Constituent** も要求条件(Requirements)を満たします。 |
| **URI**   | ❌   | ❌       | 材料のUniform Resource Identifier。リソースは名前と定義を含み、できればISO 23386に準拠する必要があります。                                                                                                                                                              | 有効なURIの一つのソースは[bSDD](https://search.bsdd.buildingsmart.org/)です。"Plywood"のURIの例：[https://identifier.buildingsmart.org/uri/cei-bois.org/wood/1.0.0/class/8dca70a2-01a2-489b-9381-fbeff09db8dc](https://identifier.buildingsmart.org/uri/cei-bois.org/wood/1.0.0/class/8dca70a2-01a2-489b-9381-fbeff09db8dc)。 |

パラメータが指定されていない場合、名前やカテゴリに関係なく、任意の **Material** が存在する必要があることを意味します。

## 例

| 適用対象(Applicability)の意図                                                                                         | 要求条件(Requirements)の意図                                                                                               | ファセット定義              |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| 材料を持つ任意のエンティティ                                                                                      | エンティティは材料を持つ必要があります                                                                                     | パラメータなし               |
| 木材から作られたすべてのエンティティ                                                                                     | エンティティは木材で作られている必要があります                                                                                 | Value="wood"                |
| レンガから作られたすべてのエンティティ                                                                                    | エンティティはレンガで作られている必要があります                                                                                | Value="brick"               |
| コンクリートまたは鋼材のいずれかから作られたすべてのエンティティ                                                                 | エンティティ（例：基礎杭）はコンクリートまたは鋼材のいずれかで作られている必要があります                                         | Value=["concrete", "steel"] |
| "CON"で始まり2桁の数字が続く、CON01、CON02等のコードで名前が付けられた材料を持つ任意のエンティティ | エンティティは、CON01、CON02等のような「CON」の後に2桁の数字が続く命名方式の材料を持つ必要があります。 | Value="CON[0-9]{2}"         |
