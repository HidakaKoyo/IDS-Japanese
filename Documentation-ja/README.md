# IDSのドキュメント

- [UserManual](UserManual/) には、IDSの内容と使用方法の説明が含まれています。[README](UserManual/README.md)ファイルから始めてください。
- [Examples](Examples/) には、いくつかのサンプル.idsファイルが含まれています
- [ImplementersDocumentation](ImplementersDocumentation/) には、ソフトウェア開発者向けの技術的な追加説明が含まれています。例えば、ソフトウェアが数値の[tolerance](ImplementersDocumentation/tolerance.md)をどのように処理すべきかなどです。このフォルダには、ソフトウェア実装の読み取りとチェック機能の正確性を検証するための250以上のテストファイルペア（.idsと.ifc）のスイートも含まれています：[TestCases](ImplementersDocumentation/TestCases/)。
