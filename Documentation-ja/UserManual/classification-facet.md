# 分類ファセット

**分類システム** は、要素を分類するための定義された階層です。人気のある**システム** の例として「Uniclass 2015」があります。**システム** 内では、「EF_25_10」や「EF_25_10_25」のような短い**参照** コードの階層があり、より詳細なレベルで要素を分類します。IFCモデル内のあらゆるオブジェクトは**分類参照** を持つことができます。

**分類ファセット** は**エンティティファセット** とは異なります。**エンティティファセット** は組み込みのIFCクラスと事前定義されたタイプに制限されており、これらは**分類** の方法としても機能する場合があります。対照的に、**分類ファセット** で指定された**システム** は、第三者の非IFC**システム** を参照します。

IFCモデルは**分類** の名前、日付、バージョン、その他のデータを追跡して**システム** を一意に識別し、**参照** の階層も保存する場合があります。そのため、**分類** の要求条件は**プロパティファセット** ではなく**分類ファセット** を使用する必要があります。

**分類** は**適用対象** エンティティを識別したり、アセット管理システム、作業分解構造、調整要求条件などのワークフローで、エンティティが指定された**分類** システムに従うことを**要求** する優れた方法です。

## パラメータ

|パラメータ|必須|制限許可|許可値|意味|
|---|---|---|---|---|
|**System**|✔️|✔️|**分類システム** の名前|要素は、この名前を持つ分類システムの一部である参照で分類される必要があります|
|**Value**|❌|✔️|**分類システム** 内の**参照** コードの値|要素は、この値と一致するコードを持つ**参照** で分類される必要があります。値は通常、分類レベルを示す区切り文字を持つ短いコードです|
|**URI**|❌|❌|クラスの統一資源識別子|クラスの標準化された定義を参照するために使用され、解釈の一貫性を保証します。対象リソースには名前と定義を含む必要があり、できればISO 23386に準拠する必要があります。これは、IDSチェックの対象ではないオプション基本属性です - IFCモデルは同じURIやURIを持つ必要はありません。有効なURIの一つの情報源は[bSDD](https://search.bsdd.buildingsmart.org/)で、「Beam」のURIの例は[https://identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam](https://identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam)です。|

パラメータが指定されていない場合、**システム** 名や**参照** コードに関係なく、何らかの**分類** が存在する必要があることを意味します。

## 例

| 適用対象の意図                                        | 要求条件の意図                                                | ファセット定義                                    |
| ---------------------------------------------- | ------------------------------------------------------ | ------------------------------------------ |
| 分類されたあらゆる要素                                    | エンティティは分類されている必要があります                                  | パラメータなし                                    |
| OmniClassを使用して分類されたあらゆるエンティティ                  | エンティティはOmniClassを使用して分類されている必要があります                    | System="OmniClass"                         |
| OmniClassまたはUniclass 2015のいずれかで分類されたあらゆるエンティティ | エンティティはOmniClassまたはUniclass 2015を使用して分類されている必要があります    | System=["OmniClass", "Uniclass 2015"]      |
| "EF_25_10_25"の分類参照を持つあらゆるエンティティ                | 要素（例：壁）は参照"EF_25_10_25"を使用して分類されている必要があります             | Value="EF_25_10_25"                        |
| EF_25_10で始まるUniclass 2015分類参照を持つあらゆる要素         | エンティティ（例：壁）はUniclass 2015を使用し、EF_25_10で始まる参照を持つ必要があります | System="Uniclass 2015", Value="EF_25_10.*" |
